# 02: Penyusunan Laporan Akademik PB1 Kelompok 6 (Markdown & Word .docx)

**What to build:** Penyusunan dokumen laporan akademik komprehensif untuk tugas mata kuliah Rekayasa API "Project Based 1: Pengembangan Aplikasi Berbasis API dari Hasil Praktikum" untuk Kelompok 6.
